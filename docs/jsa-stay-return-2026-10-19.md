# Stay in JSA with a visible Tickets return

Stay on JSA preserves the exact completion callback for the current authenticated
owner/session before consuming transient launch state, then goes to home. The
ordinary welcome is suppressed for that session after Stay; a new governed read
request still gets its request-bound entry. Home/history/current-record/saved-record
footers offer Back to Tickets in the left slot. Standalone entry has no return
button; Saved JSAs remains in More. Return state is checked again at tap time.

Validation: TypeScript, Welcome entry, Stay-return owner isolation, and governed
terminal regressions. No build, installation, deployment, or record changes.
